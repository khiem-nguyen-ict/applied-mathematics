# Applied Mathematics

A collection of Jupyter notebooks introducing applied mathematics using Python with Anaconda packages such as NumPy, SciPy, SymPy, Pandas, and Matplotlib.

## Contents

- **[Introduction.ipynb](#)** — Introduction to using Anaconda packages, environment setup, and importing required libraries.
- **[Exercises.ipynb](#)** — Practice exercises covering number sequences, arithmetic sums, series, limits, and recurrence relations.

## Topics Covered

- Number sequences (arithmetic sequences)
- Arithmetic and geometric sums
- Series and limits of sequences
- Recurrence relations
- Symbolic computation with SymPy
- Numerical computation with NumPy and SciPy
- Data manipulation with Pandas

## Environment Setup

This project uses a dedicated conda environment named `APPLIED_MATH`. Create it with:

```bash
conda create --name APPLIED_MATH python=3.12 ipykernel numpy \
scipy sympy pandas matplotlib networkx cryptography -y
```

## Requirements

- Python 3.12
- Conda (Anaconda or Miniconda)
- Jupyter Notebook / JupyterLab

## Packages

- math (standard library)
- numpy
- scipy
- sympy
- pandas
- matplotlib
- networkx
- cryptography

## Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/khiem-nguyen-ict/applied-mathematics.git
   cd applied-mathematics
   ```

2. Create and activate the environment:

   ```bash
   conda activate APPLIED_MATH
   ```

3. Open the notebooks in Jupyter:

   ```bash
   jupyter notebook
   ```
